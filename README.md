## CN2 GIA和普通CN2到底差在哪

先说清楚一个容易混淆的概念。国内常说的"CN2"其实分两种：CN2 GT和CN2 GIA。

CN2 GT是电信CN2骨干网的普通版本，虽然比传统163骨干网快，但用户量大，晚高峰依然会拥堵。CN2 GIA（Global Internet Access）则是电信面向企业级客户的高端专线产品，带宽资源独享程度更高，价格也贵得多，所以一般只有做外贸、跨境电商、企业远程办公或者对网络稳定性要求较高的场景才会专门选它。

判断一台VPS是不是真的走CN2 GIA线路，光看商家宣传没用，得看实际路由。用`tracert`或者`mtr`跑一下，如果去程和回程都能看到163.xxx.xxx.xxx这类电信CN2骨干网段，且晚高峰（一般指19点到23点）延迟和丢包没有明显跳变,基本就能确认是真GIA。反过来，如果白天延迟80ms，晚上飙到200ms以上还伴随丢包，那大概率是普通线路甚至BGP中转在冒充GIA。
